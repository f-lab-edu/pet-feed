# 2026-10-24 개발 상태

## 게시글 도메인

- post-service에 Post 엔티티, JPA 저장소, 서비스, HTTP 컨트롤러를 구현했다.
- 등록 `POST /api/v1/posts` (201), 상세 `GET /api/v1/posts/{id}` (200), 전체 수정 `PUT /api/v1/posts/{id}` (204), 삭제 `DELETE /api/v1/posts/{id}` (204).
- 본문은 공백 불가, 최대 5,000자이며 썸네일 URL은 선택 사항이고 최대 2,048자다. 수정은 본문과 썸네일을 교체하며 null 썸네일은 기존 값을 비운다.
- 수정·삭제는 작성자만 가능하다(403). 없는 게시글은 404다.
- 기존 Feign 계약에 맞춰 회원별 목록과 개수 조회를 구현했다. 목록은 ID 내림차순 20개, 최초 cursor=0, 이후 nextCursor를 사용하며 마지막 nextCursor는 null이다.
- Facade가 회원 상태를 조회하고 상세·등록 응답에 작성자 표시 정보를 조합한다. 탈퇴한 회원의 기존 게시글과 작성자 키는 보존하고, 탈퇴 회원의 쓰기는 차단한다. 회원 조회 실패를 탈퇴 상태로 대체하지 않는다.
- 기존 PostFeignClient의 목록·개수 계약과 사용자 작업을 유지하며 CRUD 메서드를 추가했다.
- 실행 예시는 `apps/api-gateway/http/posts.http`에 있다. Gateway에서 JWT를 검증하고 내부 X-User-Key를 전달하는 기존 구조를 사용한다.

## 제한

- DB는 기존 메모리 H2/create-drop 설정이므로 재시작하면 데이터가 사라진다.
- 이미지 업로드, 좋아요, 댓글은 이번 범위에 포함하지 않았다. 목록의 좋아요·댓글 개수는 0이다.
- 회원 상태 확인과 게시글 쓰기는 서로 다른 서비스의 작업이다. 확인 직후 탈퇴하는 동시 요청의 원자성은 보장하지 않는다.
- 내부 서비스 접근 통제와 Gateway를 포함한 전체 E2E는 별도 검증이 필요하다.

## 검증

- 도메인 단위 테스트, H2/MockMvc 통합 테스트, Facade 호출 조정 테스트를 추가했다.
- 실행 명령: `.\gradlew.bat :post-service:test :facade:test :user-service:test :api-gateway:test --no-daemon`
- 실행 결과: BUILD SUCCESSFUL. post-service 6개, Facade 32개, user-service 19개로 총 57개 테스트가 통과했다. 신규 테스트는 총 12개다.
- Gateway는 test NO-SOURCE로 컴파일만 검증했다. 전체 서비스 기동 E2E 및 운영 DB 검증은 수행하지 않았다.
- `git diff --check`를 통과했다.
