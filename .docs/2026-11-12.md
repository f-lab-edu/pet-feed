# 2026-11-12 PR #18 품질 검사 수정

- 화면 전환·검색·로그아웃 이벤트에서 게시글 조회 Promise를 await하고 초기 조회의 오류 처리기를 추가했다.
- MP4의 끝까지 이어지는 박스 크기를 long 연산으로 계산한다.
- 미디어 스모크 스크립트는 파일 경로 인자 대신 표준 입력으로 MP4를 받는다. cmd/bash에서 `node scripts/media-smoke.mjs < sample.mp4`로 실행한다. PowerShell에서는 `cmd /c "node scripts/media-smoke.mjs < sample.mp4"`를 사용한다.
- 스모크 HTTP 요청은 허용된 로컬 API 경로만 사용하고 리디렉션을 거부한다.
- 검증: 미디어 서비스 테스트 성공, 스모크 경로 회귀 테스트 2개 성공, UI·스모크 JS 문법 검사 성공. 실제 서비스 7개를 실행하는 업로드 E2E는 수행하지 않았다.
