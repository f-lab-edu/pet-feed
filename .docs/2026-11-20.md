# 2026-11-20 홈 피드 구현

## 로컬 변경 통합

- 기존 작업 폴더의 변경을 커밋으로 보존하고 PR #22까지 반영된 main을 통합했다. 피드의 Instant 시간 계산, 복잡도 개선, 명시적인 경로 변수 바인딩을 유지한다.
- 회원별 피드 설명에 닉네임을 표시하고 글이 없는 경우 프로필 닉네임을 사용한다. 작성자 이름이 없을 때 내부 회원 키를 이름으로 표시하지 않으며 내 기록 조회 시 검색창의 본인 키를 숨긴다.
- 늦게 도착한 프로필 응답은 새 홈 화면의 이름을 덮어쓰지 않도록 조회 세대 검사 이후에 적용한다.
- 의존성 그래프를 `.docs`로 이동하고 색인에 연결했다. PowerShell 모듈 분석 캐시는 Git 추적에서 제외한다.
- 통합 후 전체 Gradle 테스트 통과, UI·미디어 스크립트 테스트 12개 통과. 빈 목록의 닉네임, 프로필 조회 실패, 화면 전환 후 늦은 응답을 검증했다. 실제 서비스 전체 기동·브라우저 E2E는 미실행.

- 팔로우 글과 발견 글을 7:3 목표로 섞는 홈 피드 API와 화면 연결을 추가했다.
- 최근 30일 최대 500개 후보, 최신성·시드 난수 점수, 연속 작성자 완화, 후보 부족 시 대체 규칙을 적용했다.
- 세션의 고정 순서와 사용자별 커서로 페이지 중복을 방지한다. 콘텐츠와 댓글 수는 매번 다시 조회한다.
- 설계·API·제약은 [홈 피드 알고리즘](feed-algorithm.md)에 기록했다.
- 기존 닉네임 UI 변경, MediaController와 CommentListResponse의 로컬 변경은 보존한다.

## PR #20 SonarCloud 지적 수정

- 신뢰성 등급 실패 원인인 시간대 없는 경과 시간 계산을 수정했다. 게시글 서비스가 후보의 작성 시각을 UTC Instant로 전달하고 순위 계산도 Instant끼리 수행한다. 기존 DB 컬럼과 게시글 상세 계약은 유지한다.
- 시차가 다른 동일 시각과 서머타임 전환 구간의 실제 경과 시간을 검증하는 점수 테스트를 추가했다.
- 후보 정렬·혼합과 화면 조회·상태 갱신 책임을 분리해 복잡도를 낮췄다. 화면 설명의 중첩 조건식, 커서 정규식, 테스트의 컬렉션·시간대 지적도 정리했다.
- 수정 후 관련 백엔드 테스트 83개, UI 회귀 테스트 7개가 통과했다.

## API 프리픽스 공통화

- `api-contracts`의 `ApiPaths`에 `API_ROOT`, `API_V1`, `INTERNAL_V1`을 정의하고 컨트롤러, Feign·RestClient, Gateway 보안 설정에 적용했다.
- 기존 URL과 `/api/**` 프록시 범위를 유지한다. 새 API 버전은 기존 상수 값을 바꾸지 않고 별도 상수로 추가한다.
- 정적 UI는 `app.js`의 `API_V1`을 일반 API 요청과 미디어 업로드·다운로드에서 공유한다.
- HTTP 계약 테스트는 실제 URL 문자열을 유지해 경로 변경을 감지한다.
- 최신 main에서 별도 worktree로 분리하여 기존 미커밋 변경은 포함하지 않았다.
- PR 브랜치 검증: `gradlew.bat --gradle-user-home C:/Users/lenovo/.gradle test --console=plain` 성공, 백엔드 118개 실패·오류 0. `node --test scripts/ui-regression.test.mjs scripts/media-smoke.test.mjs` 9개 통과. 실제 서비스 기동·브라우저 E2E는 미실행.
