## API 프리픽스 공통화

- `api-contracts`의 `ApiPaths`에 `API_ROOT`, `API_V1`, `INTERNAL_V1`을 정의했다. 컨트롤러, Feign·RestClient 호출, Gateway 보안 설정의 프리픽스를 공통 상수로 교체했다.
- 기존 URL과 Gateway의 `/api/**` 프록시 범위는 유지한다. v2 도입 시 v1 상수를 변경하지 않고 별도 버전 상수를 추가한다.
- 정적 UI의 일반 API 호출·미디어 업로드·다운로드는 UI 내부의 `API_V1` 상수를 공유한다.
- 기존 HTTP 계약 테스트의 URL 문자열은 유지하여 상수 값 변경으로 실제 경로가 달라지면 감지하도록 했다. 기존 로컬 변경을 보존한 상태에서 작업했다.
- 검증: `gradlew.bat --gradle-user-home C:/Users/lenovo/.gradle test --console=plain` 성공. 백엔드 테스트 결과 XML 기준 117개, 실패·오류 0. `node --test scripts/ui-regression.test.mjs scripts/media-smoke.test.mjs` 9개 통과. `git diff --check` 통과.
- 이번 작업의 실제 서비스 기동·브라우저 E2E는 미실행이며 커밋·PR은 생성하지 않았다.
