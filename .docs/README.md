# 개발 상태 기록

작업을 시작하거나 대화 맥락을 복구할 때 [프로젝트 작업 규칙](RULES.md)을 먼저 확인한다.

날짜별로 `.docs/YYYY-MM-DD.md`에 프로젝트 상태를 기록한다. 날짜는 한국 시간(Asia/Seoul)을 기준으로 한다.

- 같은 날의 추가 작업은 해당 날짜 파일에 추가한다.
- 다른 날짜의 작업은 새 파일로 작성하고, 이전 기록은 당시 상태로 보존한다.
- 구현 내용, 설계 결정, 테스트 명령과 결과, 제한 사항, 다음 작업, 관련 PR을 기록한다.
- 테스트 통과와 실제 운영 환경 검증을 구분해서 작성한다.
