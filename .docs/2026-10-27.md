# 2026-10-27 개발 상태

## 댓글

- 게시물 서비스에 댓글 엔티티와 저장소, 작성·목록·수정·삭제 API를 추가했다.
- `/api/v1/posts/{postId}/comments`에서 작성(201), 최신순 목록(200), `/{id}`에서 수정·삭제(204)를 제공한다.
- 본문은 공백 불가, 최대 1,000자다. 작성자만 수정·삭제할 수 있고 다른 게시물의 댓글 ID는 404로 처리한다.
- 목록은 20개씩 커서 조회하며 Facade에서 작성자 정보를 조합한다. 탈퇴 회원의 쓰기를 차단하고 기존 댓글은 유지한다.
- 게시물 목록에 실제 댓글 수를 반영하며 게시물 삭제 시 댓글을 같은 트랜잭션에서 삭제한다.
- HTTP 요청 예제: `apps/api-gateway/http/comments.http`.
- 검증: `.\gradlew.bat :post-service:test :facade:test --console=plain` 성공. 신규 댓글 통합 테스트 3개와 Facade 테스트 2개 포함.
- 제한: 기존 메모리 H2/create-drop 설정을 유지한다. 실제 서비스 전체 기동 E2E와 운영 DB는 별도 검증이 필요하다.
- 게시물 PR #12를 기반으로 댓글 PR을 분리한다.
