# 2026-10-27 개발 상태

## 댓글

- 게시물 서비스에 댓글 엔티티와 저장소, 작성·목록·수정·삭제 API를 추가했다.
- `/api/v1/posts/{postId}/comments`에서 작성(201), 최신순 목록(200), `/{id}`에서 수정·삭제(204)를 제공한다.
- 본문은 공백 불가, 최대 1,000자다. 작성자만 수정·삭제할 수 있고 다른 게시물의 댓글 ID는 404로 처리한다.
- 목록은 20개씩 커서 조회하며 Facade에서 작성자 정보를 조합한다. 탈퇴 회원의 쓰기를 차단하고 기존 댓글은 유지한다.
- 게시물 목록에 실제 댓글 수를 반영하며 게시물 삭제 시 댓글을 같은 트랜잭션에서 삭제한다.
- HTTP 요청 예제: `apps/api-gateway/http/comments.http`.
- 검증: `.\gradlew.bat :post-service:test :facade:test --console=plain` 성공. 신규 댓글 통합 테스트 3개와 Facade 테스트 2개 포함.
- 제한: 기존 메모리 H2/create-drop 설정을 유지한다. 실제 서비스 전체 기동 E2E와 운영 DB는 별도 검증이 필요하다.
- 게시물 PR #12를 기반으로 댓글 PR을 분리한다.

## 임시 화면

- 댓글 PR: https://github.com/f-lab-edu/pet-feed/pull/13 (대상: `feature/post-domain`, 기반 PR #12).
- `feature/temporary-ui` 브랜치에 Gateway 정적 화면을 추가했다. `/` 및 `/ui`는 `/ui/index.html`로 이동한다.
- 데모 모드에서 예시 기록, 게시물·댓글 작성·수정·삭제와 브라우저 저장을 제공한다.
- 실제 API 모드에서 회원가입·로그인, 내 기록/회원 키 검색, 게시물·댓글 CRUD 및 커서 조회를 연결했다.
- 전체 피드 API, 이미지 업로드, 좋아요는 지원하지 않는다. 사용법은 `apps/api-gateway/UI.md`에 기록했다.
- API 프록시는 `/api/**`로 제한하고 화면의 GET 경로만 익명에게 열었다. 기존 API 인증은 유지한다.
- 검증: `node --check apps/api-gateway/src/main/resources/static/ui/app.js` 성공. Gateway `UiIntegrationTest` 2개 통과(실패/오류 0): 익명 화면·정적 자원 접근과 보호 API의 익명 요청 차단을 확인했다. 실행한 Gateway에서 화면 HTTP 200 응답도 확인했다.
- 제한: 브라우저 도구가 현재 URL을 확인하지 못해 시각 검증을 완료하지 못했다. 실제 로그인부터 CRUD까지의 브라우저 E2E는 미검증이다.
